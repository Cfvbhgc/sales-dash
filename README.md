# SalesDash

Дашборд аналитики продаж: показатели, графики выручки, таблица сделок, клиенты, продукты и аналитика.

**Демо:** https://cfvbhgc.github.io/sales-dash/

## Что внутри

- **Обзор:** выручка крупным числом и три показателя (заказы, новые клиенты, средний чек) с изменением к прошлому периоду и мини-графиками; цифры досчитываются при показе и перетекают при смене периода.
- **Период 7 дней / 30 дней / 90 дней / год:** график выручки плавно перестраивается (в том числе между разным числом точек), рядом прошлый период для сравнения; перекрестие с подсказкой, управление стрелками.
- **Выручка по категориям:** сегментированная полоса с долями и легендой.
- **Сделки сейчас:** живая лента новых сделок и всплывающие уведомления.
- **Транзакции:** поиск с подсветкой совпадений, сортировка по колонкам (строки переезжают на новые места), страницы, экспорт в CSV.
- **Клиенты:** список с мини-графиками покупок; карточка клиента выезжает сбоку с графиком по месяцам и последними сделками.
- **Продукты** и **аналитика:** воронка продаж, конверсия по месяцам, менеджеры и регионы по выручке.
- **Командная строка ⌘K:** разделы, клиенты, продукты и сделки, выбор стрелками.
- **Светлая и тёмная тема** (переключение круглой волной от кнопки), **русский и английский** язык, плотная таблица — настройки запоминаются.
- У каждого графика есть табличный вид; учтены клавиатура и режим «уменьшить движение»; на телефоне меню внизу.

Графики свои, на SVG, без библиотек; цвета графиков проверены на различимость при нарушениях цветового зрения.

## Стек

React 19, TypeScript, Vite.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3390
npm run build    # сборка в dist/
```

Данные демонстрационные и генерируются в `src/data.ts`.
